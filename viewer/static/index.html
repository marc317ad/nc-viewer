Catalog: click a file to open it in the focused pane, shift-click for the next pane; Compare on a scene opens DSFOPT and C2RCCOPT side by side. Empty min/max means auto p2..p98 (the values used appear as placeholders).

RGB in a pane header shows a false-colour composite: pick a preset (true colour, NIR, SWIR, red edge) or any three float bands for R, G, B. Each channel is stretched p2..p98 on its own; shared uses one range for all three, γ brightens the dark end, min/max apply to every channel. With Link bands on, the other panes follow by wavelength.
